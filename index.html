This tool extracts the direct CDN video URL from a DiskWala shared link and plays it in a clean HTML5 player (with hls.js for HLS/m3u8 streams). Extraction needs a backend because browsers block cross-origin (CORS) requests to the DiskWala API. Pick a source:

Calls /api/resolve?url=… then /api/m3u8?url=…. If the fast backend is offline it falls back to the in-browser extractors automatically.

Use {URL} where the encoded link goes, or append ?url=… automatically. Response may be JSON (with stream_url/download_url/url/src) or a raw URL.

Settings persist in localStorage.

DiskWala stores files on a CDN and shares them through short “surl” links (diskwala.com/sharing/link?surl=…). The official app fetches the real CDN download/stream URL from its API. This tool does the same from your browser, with three strategies in order:

  1. Free m3u8 extractor (default, no key): we call the ronnieverse extractor (the same one behind PlayDiskWala) that returns a clean HLS .m3u8 for any DiskWala link, and play it with hls.js — no app, no ads, no login.
  2. TeraBox/DiskWala API: if you have an extraction API key, it’s called directly for the most reliable, high-speed stream + download URLs.
  3. Custom endpoint: point it at your own extractor.

Why a backend/proxy? DiskWala’s API sends Access-Control-Allow-Origin headers that most browsers reject on a random origin, so a small proxy is needed. The built-in “Public CORS proxy” works out of the box for many links; if a link is rate-limited or the share page hides the stream, drop in a free extraction API key (TeraBox/DiskWala) under the Extraction API tab.

Download note: the “Download” button opens the raw CDN file in a new tab; for large videos, copy the stream URL and download it with any downloader.

Single-file webapp — save this as adfreewala.html and open it in any browser (or host it on GitHub Pages / Netlify). No data leaves your device except the link you paste (to the chosen backend).
